Download-Button Style Vorschlaege

Suggestion-only: bestehende Icons, keine Drop Shadows, und ein deutlich ruhigerer Hover-State. Die unterschiedlichen Formen bleiben bewusst erhalten: runde Overlay-Buttons bleiben rund, Shorts bleibt groesser, und der alte 8px-Button behaelt seine kantigere Form.

A: Ruhiger Hover

Kleinste Aenderung. Die Defaults bleiben nah am Bestand, Hover wird nur etwas heller und mintiger.

B: Angeglichener Default

Der alte 8px-Button bekommt dieselbe dunkle Teal-Flaeche wie die neueren Buttons, aber ohne Schatten und ohne Formwechsel.

Default
Hover

C: YouTube-Overlay nah

Fuer dichte Listen und Thumbnail-Overlays. Transparent im Default, beim Hover nur eine dunkle Flaeche mit mintfarbener Kontur.

Ghost reveal default
  • Empfohlene Richtung

    B fuer sichtbar platzierte Buttons, C fuer Hover-Reveal und Thumbnail-Overlays.

  • Warum das passt

    Der Hover bleibt im Extension-Farbraum, wirkt aber nicht wie ein CTA und konkurriert weniger mit YouTubes eigener UI.

D: Segmentierte Channel-Pill

Vorschlag fuer den kombinierten Channel-Button auf Videoebene: gleiche runde, laengliche Pill wie bei YouTube-Segmentbuttons. Beide Segmente teilen dieselbe dunkelblaue Flaeche; Hover hellt nur das aktive Segment in Blau auf.

Default

Einheitliche dunkelblaue Grundflaeche, keine graue YouTube-Flaeche, keine Schatten.

Hover auf Download-Segment

Nur das Segment unter dem Pointer wird heller blau. Der Rest der Pill bleibt ruhig und lesbar.
